CW2_M01095580_CST1510

Description

This repository contains coursework for module CST1510.
It demonstrates my ability to design, develop and deploy a Python-based application with secure coding practices, version control and user-friendly features.

Features
- Streamlit dashboard with category, severity and date range filters
- Key Performance Indicators (KPIs) and charts for clear data 

visualization
- Secure login with password validation
- Error handling and reset functionality
- Personalized welcome message and logout option
- Data export/download functionality for filtered results

Installation
- Clone the repository:
git clone https://github.com/Umaya-16/CW2_M01095580_CST1510.git
- Navigate into the project folder:
cd CW2_M01095580_CST1510
- Install dependencies:
pip install -r Requirements.txt

Usage
Run the Streamlit app:
streamlit run main.py

Notes
- The code is located on the master branch.
- Sensitive information (e.g., API keys) has been removed for security.
- This project was developed as part of coursework for CST1510 and demonstrates secure coding and dashboard design best practices.
